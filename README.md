# CivicSense – AI-Verified Waste Reporting, Cleanliness Rating and Rewards Platform

Live demo: https://selvamnivetha044-cmyk.github.io/Civicsense-/

Report it. Clean it. Prove it. Earn for it.

## Features
- AI Live Scan: on-device littering, vehicle and number-plate detection with evidence and fines
- Citizen waste reporting in 3 sectors with place search, pin and live GPS
- After-cleaning photo check with a cleanliness score (Great / Better / Good / Bad) and automatic resolve
- Rating-based points, badges, podium, monthly leaderboard and Champion of the Month
- Live waste map: waste level for any searched or pinned place
- Officer dashboard: PIN login (hashed), sector queues, lockout, audit log
- UPI donation with public transparency report (CSV)
- Civic sense lessons, quiz and daily pledge
